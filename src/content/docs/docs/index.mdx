ZebraByte brings governance, risk, compliance, privacy and security workflows together for engineering, security, compliance teams and professional advisers. The platform is delivered as **ZebraByte Cloud SaaS**. Organizations can operate it directly, advisers can use it across client work, or ZebraByte can run the program through Managed Compliance.

## Architecture and migration reference

The documentation also preserves technical material from the platform's earlier deployment lineage, including Docker Compose and Kubernetes architecture. ZebraByte itself is **not distributed as open-source or self-hosted software**. Those pages remain available as architecture, security and migration reference rather than as supported ZebraByte installation instructions.
