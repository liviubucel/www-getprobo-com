ZebraByte uses and extends an open-source governance, risk and compliance platform for engineering, security and compliance teams. The platform core documented here is derived from the MIT-licensed Probo project. We preserve upstream technical names where compatibility matters and layer ZebraByte security, privacy and managed-service workflows around that core.

Use these docs to understand the product model, operate a compliance program, automate records and choose a deployment.
