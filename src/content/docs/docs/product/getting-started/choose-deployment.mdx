ZebraByte is delivered as a **Cloud SaaS platform**. You do not choose between a ZebraByte cloud edition and an open-source/self-hosted edition; instead, you choose **who operates the compliance program and how much expert support you want**.

## Choose the model that fits your organization

### Self-service Cloud

Choose **ZebraByte Cloud** when your internal team wants to run the compliance program directly. ZebraByte operates the application infrastructure, updates, security controls, backups and platform availability while your organization manages its compliance content, users, integrations and evidence.

This model is a good fit when you already have internal security, compliance or governance expertise and mainly need a structured system of record and automation layer.

### Professional / adviser use

Consultants, lawyers, DPOs, GRC specialists and other professional advisers can use the same ZebraByte Cloud platform as the operating environment for compliance work delivered to clients.

This model is useful when the specialist wants software for:

- framework and control management;
- risk and vendor registers;
- policy and evidence workflows;
- audit preparation;
- access reviews and integrations;
- repeatable client delivery without maintaining a separate self-hosted stack.

### ZebraByte Managed Compliance

Choose **Managed Compliance** when you want ZebraByte specialists to take on more of the work. The underlying product remains the same cloud platform, but ZebraByte can help operate the program: controls, policies, evidence, risk work, remediation tracking, audit preparation and recurring compliance activities.

The exact responsibility split depends on the engagement and framework.

## Responsibility model

| Area | **Self-service / Professional** | **Managed Compliance** |
| --- | --- | --- |
| Cloud infrastructure | ZebraByte | ZebraByte |
| Platform updates and security | ZebraByte | ZebraByte |
| Organization setup | Customer/adviser | Shared or ZebraByte-led |
| Framework and control operation | Customer/adviser | Shared or ZebraByte-led |
| Evidence collection | Customer/adviser with automation | Shared / ZebraByte coordinated |
| Policies and remediation | Customer/adviser | Shared / ZebraByte supported |
| Audit preparation | Customer/adviser | ZebraByte-supported |
| Final business decisions and approvals | Customer | Customer |

## ZebraByte is not distributed as self-hosted software

ZebraByte does not provide an open-source edition or a supported customer-operated Docker/Kubernetes distribution. This avoids making each customer responsible for patching, secrets, database operations, object storage, monitoring, backups and upgrade compatibility.

The documentation still preserves the platform's earlier Docker Compose and Kubernetes material as **technical lineage and migration reference**. It can help architects understand deployment assumptions, data services and historical operational boundaries, but those pages are not instructions for installing ZebraByte.
